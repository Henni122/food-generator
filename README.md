FOOD GENERATOR

Just a fun little project to build my fundation in Spring and JS. Got this idea a long time ago but i just now started on working on it because i felt i was not "ready" to start building something.

The idea behind this is so that my mom can use this if she needs ideas for what we should eat to dinner, if we the kids comes up with the same response as always which is "i dont know"...

What are the features i want to implement in the near future?
- A way for you to filter out what food the generator generates (middle-eastern food, european food etc)
- A "prettier" webpage (it's really basic now)
- Not sure yet, but maybe a DB (tho i don't know what i should be storing)
